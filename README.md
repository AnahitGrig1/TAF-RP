**Playwright / JavaScript Test Automation Framework**

Overview

This is a lightweight test automation framework built using Playwright JS. 
It enables fast, reliable, and cross-browser testing for web applications. 
The framework is designed for easy setup, maintainability, and scalability for small to medium-sized projects.


Clone the repository:

   `git clone https://github.com/AnahitGrig1/TAF-RP.git`

Install dependencies:
   `npm install`


To run all tests:
   `npx playwright test`

To run a specific test file:
   `npx playwright test tests/example.spec.js`
